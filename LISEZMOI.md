# Add-in Outlook Odoo + sections Devis/Commandes et Commandes d'achat

Dérivé de odoo/mail-client-extensions (branche v1, LGPL-3).
Ajouts : classes SaleOrder/PurchaseOrder, composants SectionSaleOrders et
SectionPurchaseOrders, branchement dans ContactPage, mode « lecture seule »
dans Section, nouvelle identité dans manifest.xml.

À utiliser avec le module serveur mail_plugin_sale_purchase.
Le site doit être publié à la racine de <compte>.github.io
(dépôt nommé <compte>.github.io), voir le guide.
